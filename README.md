# Academic Co-Pilot

AI-powered academic planning and teaching assistant for faculty.

## Project Goal

Academic Co-Pilot helps teachers create academic plans, teaching materials,
course outcomes, CO-PO mappings, assessments, and other academic resources
using AI.

## Architecture

The project consists of three main services:

- `frontend` - React + TypeScript
- `backend` - Node.js + Express + TypeScript
- `ai-service` - FastAPI + Python
