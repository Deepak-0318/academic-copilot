## Course Objectives :

- a) Introduce the core technologies and principles of modern web development.
- b) Develop the ability to design and create user-centered, accessible websites.
- c) Familiarize students with the UX design process, including planning, prototyping, and usability testing.
- d) Provide hands-on experience in implementing and testing web interfaces, laying a foundation for further learning and professional growth.

## Course Outcomes: After completing the course, the students will be able to: -

- a) Understand the basic structure of HTML and apply CSS to design well-structured and visually styled web pages.
- b) Analyze and manipulate the Document Object Model (DOM) using JavaScript to create dynamic and interactive web pages.
- c) Understand the principles of user experience (UX) design to create user-friendly and accessible web interfaces.
- d) Apply web development and UX principles to develop a complete web project from concept to implementation.
