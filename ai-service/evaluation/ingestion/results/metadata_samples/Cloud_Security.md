## Course Objectives:

- Explain fundamental cloud security principles, architectures, service models (IaaS, PaaS, SaaS), and the shared responsibility model to effectively manage risks in cloud environments.
- Apply data protection strategies (e.g., encryption, data loss prevention) and implement identity and access management (IAM) mechanisms to enforce secure access control in cloud platforms like AWS and GCP.
- Analyze network security controls (e.g., firewalls, VPCs), vulnerability assessment techniques, and incident response frameworks to secure and respond to threats in cloud infrastructure.
- Design and plan cloud migration strategies using industry-standard frameworks (e.g., AWS Well-Architected, Google Cloud Adoption Framework) and tools, while evaluating security best practices for compliance, governance, cost optimization, performance, and continuous monitoring.

## Lab Practicals

Experiment 1: Identity &amp; Access Management (IAM) Foundations - create users, roles, and a Permissions Boundary mock-up to illustrate shared-responsibility.

Experiment 2: Build &amp; Test a 'Cloud Firewall' Using Security Groups - harden a two-tier VPC, scan ports from an EC2 bastion, and verify SG ingress/egress rules.

Experiment 3: Vulnerability Assessment with Amazon Inspector - run Inspector 2 scans on an EC2 instance.

Experiment 4: Client-Side Encryption with AWS KMS &amp; the Encryption SDK - encrypt data locally, upload to S3, and decrypt on download

Experiment 5: AWS Application Migration Service (MGN) - Migrating an existing server or application to AWS with minimal changes using a rehosting strategy.

Experiment 6: AWS Database Migration Service (DMS) - Migrating relational databases to AWS with minimal downtime.

Experiment 7: Migration of Object Storage Data Between Amazon S3 Buckets Using AWS DataSync.

Experiment 8: Continuous Compliance Logging with AWS CloudTrail Lake - create an event data store, write Lake queries for IAM changes &amp; S3 policy updates, and set up SNS alerts.

Experiment 9: Migrate an EC2-based Web Application from Source AWS Account to Target AWS Account.

Experiment 10: GuardDuty detects the behavior and automatically isolates the instance from the network.
