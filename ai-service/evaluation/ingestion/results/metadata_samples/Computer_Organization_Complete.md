## Course Objectives :

- a) Understand the fundamental components and operations of computer systems.
- b) Analyze instruction sets and addressing modes.
- c) Explore memory hierarchy, storage systems, and input/output mechanisms, including buses and I/O interfacing.
- d) Comprehend basic concepts of instruction pipelining and overall system performance enhancement techniques.

## Course Outcomes:

- a) Describe the functional organization of a computer system and perform arithmetic operations using signed, fixed-point, and floating-point number representations.
- b) Analyze instruction set architectures, addressing modes, and instruction formats, and distinguish between CISC and RISC architectures.
- c) Evaluate memory hierarchy concepts, cache mapping techniques, replacement algorithms, cache coherence, and various I/O and secondary storage mechanisms.
- d) Explain the design and functioning of ALU, datapath, and control units, and analyze pipelined execution, hazards, and performance metrics of computer systems.
