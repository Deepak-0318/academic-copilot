## Course Objectives :

- a) Fundamental principles and applications of machine learning algorithms
- b) Implementation of preprocessing techniques to clean/transform raw datasets
- c) Evaluate regression and classification model's performance on real-time datasets.
- d) Implementation of unsupervised learning algorithms for pattern discovery and analysis in datasets.
- e) Build Multilayer Perceptron to perform classification

## Course outline (Syllabus of the course) Syllabus:

## Module - 1

## Foundations of Artificial Intelligence and Machine Learning

Overview of Artificial Intelligence, History, Can Machines Think?, Turing Test, State Space Search, and Heuristic Search. History of machine learning, Definition and types of machine learning: supervised, unsupervised, semi-supervised, and reinforcement learning algorithms. Applications of machine learning: natural language processing, sentiment analysis, language translation, and computer vision-object recognition, object detection, and object generation.

## Module - 2

## Supervised Learning Models: Regression

Linear, lasso, ridge, and polynomial regression, loss functions, MSE, MAE, RMSE, gradient descent, learning Rate, and Challenges: overfitting/underfitting and regularization.

## Module - 3

No. of hours 06

## Supervised Learning Models: Classification and Evaluation Metrics

K-Nearest Neighbours (KNN): Basics, distance metrics, choice of k, SVM, Decision Trees: Splitting criteria (Gini/entropy), tree depth, Random Forest, and Ensemble Modelling.

Model Evaluation: Metrics: Accuracy, precision, recall, F1 score, AUC-ROC, confusion matrix. Cross-Validation: Purpose, k-fold validation (applied to KNN/decision trees), and Interpreting Model Evaluation Metrics and Overview of Hyperparameter tuning: Grid search.

## Module - 4

## Unsupervised Learning

K-means clustering, Dimensionality reduction: Principal Component Analysis (PCA), and Association Rule Mining: Apriori Algorithm

## Module - 5

## Perceptron and Feed-Forward neural networks

Perceptron: logistic regression, activation function, and various types of activation functions, binary classification, error backpropagation algorithm, feed-forward neural network, Difference between feed-forward neural network and multilayer perceptron, universal approximation theorem.
