## Course Objectives :

- a) Introduce Python syntax, variables, and fundamental programming concepts.
- b) Develop the ability to use Python data structures such as lists, tuples, dictionaries, and sets.
- c) Provide hands-on practice with file handling and data analysis libraries like NumPy and pandas.
- d) Teach data cleaning, preparation, visualization, and basic statistical analysis using Python tools.

## Syllabus:

## Module - 1

## Python Programming Essentials:

Introduction to Python: History, features, applications. Setting up the Python environment: Installing Python and Jupyter Notebook. Basic Python syntax: Variables, data types, and operators, Basic I/O operations, Control Structures: Conditional statements (if, elif, else), loops (for, while, nested loops), and control flow (break, continue, pass).  Functions and Modules: Function definition, parameters , return value, recursive functions, and modular programming.

## Module - 2

## Data Structures, Class, objects and File Handling:

Data Structures: Lists, tuples, sets, and dictionaries, List and dictionary comprehensions, Arrays and 2D arrays: creation, manipulation, iterations, nested loops and applications in grid-based problems (e.g., Sudoku).Classes and objects, Instance variables and methods, File Handling: Reading and writing text files, Working with CSV files. Exception handling:Try and except, user defined exceptions.

## Module - 3

## Introduction to NumPy and pandas:

NumPy: Creating and working with NumPy arrays (1D, 2D, n-dimensional), Indexing, slicing, and reshaping arrays, Element-wise operations and broadcasting. Pandas: Series
