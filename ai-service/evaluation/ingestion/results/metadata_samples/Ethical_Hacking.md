## Course outline (Syllabus of the course)

## Syllabus:

## Module - 1 Overview of Cyber Security and Ethical Hacking

No. of hours

The cyber kill chain methodology, understanding tactics, techniques, and procedures (TTPs), overview of indicators of compromise (IoCs), overview of hacking concepts and hacker classes, different phases of hacking cycle, ethical hacking concepts and its scope, ethical hacking tools, threats and threat sources, malware and components of malware, malware countermeasures, vulnerability classification, vulnerability assessment, vulnerability management life cycle, vulnerability assessment tools and exploitation.

## Password Security, Authentication, and Countermeasures

Password cracking and password complexity, Microsoft authentication, various types of password attacks, password cracking tools, countermeasures against password attacks, social engineering techniques, insider threats, identity theft, social engineering counter measures, identity theft countermeasures.

## Module - 3

## Network and Web Application Security

Packet sniffing and types of sniffing, various sniffing techniques and tools, different sniffing countermeasures, types of DoS and DDoS -attacks, tools and counter measures, session hijacking and its types, different session hijacking tools and countermeasures, web server concepts and attacks, web server attack tools and countermeasures, web application architecture and vulnerability stack, different web application threats and attacks, web application tools, different types of SQL injection attacks, SQL injection tools, SQL injection attacks countermeasures.

## Module - 4

## Wireless and Mobile Security

Overview of wireless terminology, wireless encryption algorithms, wireless network specific attack techniques, different wireless attack tools, Bluetooth attack techniques, various wireless attack countermeasures, different wireless security tools, anatomy of mobile attack, mobile platform - attack vectors, vulnerabilities, device management, security guidelines and security tools.

## Module - 5

## IoT, OT, and Cloud Security

IoT - attacks and tools, OT-attacks and tools, IoT and OT attack countermeasures and security tools, cloud computing concepts, container technology, cloud computing threats, cloud attacks and tools, cloud attack countermeasures, cloud computing security tools, penetration testing fundamentals.
